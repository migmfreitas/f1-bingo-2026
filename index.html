STEP 1 — CREATE A GIST
Go to gist.github.com, create a new public gist with filename f1bingo2025.json and content {}. Copy the Gist ID from the URL (the long string at the end).
STEP 2 — CREATE A TOKEN
Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic). Create a token with the gist scope only. Copy it — you'll only see it once.
